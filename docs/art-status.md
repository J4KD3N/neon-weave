# Art status

Generated by `tools/art_status.gd` (S56). What every thing on screen draws with today: a sprite sheet from `content/sprites/`, or the placeholder the game generates at runtime and says so. Real art replaces a sheet file-for-file (`docs/art-pipeline.md`); a race or enemy with neither a valid sheet nor `"art": {"placeholder": "rig"}` fails the validator and this tool.

## Generated at runtime

| What | Generator | Contract |
|---|---|---|
| Tiles (30) | `PlaceholderTiles` from each tile's `art` block and the biome palette | the `art` block: shape, fill, edge, pattern, top/left/right roles, `glow` |
| Portraits | `PlaceholderActorArt.portrait_image` from class colour, race overlay and appearance | `portrait_for(speaker)` in the world; a drawn portrait replaces it there |
| Buildings (7) | `BuildingActor` blocks from the building entry | the building entry |
| Pickups (31) | `PickupActor` from `art.color` | the pickup's `art` |
| Lighting | `LightingRig`: ambient from `rules/lighting` or the palette's `ambient`, a light per tile with a `glow` role, one on the leader | `rules/lighting`, tile `art.glow` |
| Screen effects | `ScreenFx` shader: glow, or glow with scanlines and a vignette | the Screen effects setting, `--fx=` |

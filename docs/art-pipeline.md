# Art pipeline

How sprites get from an artist's file into the game, and what the game
guarantees about them. Placeholder sheets are generated by
`tools/gen_placeholder_sheets.js`; real art replaces them file-for-file.

## Files

```
content/sprites/<id>.json   sidecar (the contract)
content/sprites/<id>.png    the sheet (raw PNG; the folder has a .gdignore so
                            Godot does not import it — the game reads bytes)
```

Mods ship sheets the same way under their own `content/sprites/`.
Anything that stands on a cell points at a sheet by id:
`races/<id>.json` → `"art": {"sheet": "<id>"}`,
`enemies/<id>.json` → `"art": {"sheet": "<id>", ...}`.
No sheet (or an invalid one) falls back to the generated placeholder rig.

## Sidecar

```json
{
  "image": "trueborn.png",
  "frame": [48, 64],
  "origin": [24, 60],
  "directions": ["s", "sw", "w", "nw", "n"],
  "mirror": { "se": "sw", "e": "w", "ne": "nw" },
  "palette": { "fill": "#ff00ff", "outline": "#7f007f", "highlight": "#ff80ff", "accent": "#ffffff" },
  "animations": {
    "idle":   { "row": 0,  "frames": 4, "fps": 6,  "loop": true },
    "walk":   { "row": 5,  "frames": 6, "fps": 10, "loop": true },
    "attack": { "row": 10, "frames": 4, "fps": 12, "loop": false },
    "cast":   { "row": 15, "frames": 4, "fps": 10, "loop": false },
    "hit":    { "row": 20, "frames": 3, "fps": 12, "loop": false },
    "death":  { "row": 25, "frames": 5, "fps": 8,  "loop": false }
  }
}
```

- **frame**: cell size in pixels. Characters are ~48–64 px tall (GDD §5).
- **origin**: the feet, in frame pixels. The game puts this point on the actor's cell centre.
- **directions**: the rows you actually draw, in sheet order, named by screen-space facing (`e` = right, `s` = toward the camera, angles clockwise).
- **mirror**: facings you do *not* draw, mapped to the drawn row that gets flipped horizontally. Five drawn + three mirrored = eight facings (GDD §5 "4-direction facing mirrored to fake 8"; five because north and south cannot mirror each other).
- **palette**: source colours by role. Draw with exactly these; the game swaps them per actor (class colour for party members, `art.color` or the biome's `recolors` role for enemies). Anything not in the palette is left alone, so accents (eyes, glow) can be fixed colours.
- **animations**: each is a block of `directions.size()` rows starting at `row`, one row per drawn direction in `directions` order, `frames` columns wide. `loop` animations (idle, walk) cycle; one-shots (attack, cast, hit, death) return to idle/walk when done; `death` sticks on its last frame.

Required animations: `idle`, `walk`, `attack`, `hit`, `death`. `cast` is used for arcane abilities when present; otherwise `attack` plays.

## What the game does

`SpriteSheet` (`src/systems/art/sprite_sheet.gd`) validates the sidecar against the image, recolours by role, and builds `SpriteFrames` named `<animation>_<row>`. `ActorSprite` picks the row and flip for any screen-space direction and runs the idle/walk/one-shot state machine. `WorldActor.set_motion` and `play_action` are the only calls gameplay makes.

Validation failures are warnings at load and a failing test in CI (`tests/unit/test_content_integrity.gd`).

## Style rules (GDD §5)

- Dark, desaturated bodies; saturated neon only for meaning (class colour swaps, glows, telegraphs).
- Glow comes from lighting, not baked into sprites.
- One humanoid rig for every race; race identity is an overlay layer. For real art, ship race overlays as separate sheets with transparent backgrounds and the same frame/origin/directions/animations; the loader will composite them (not implemented yet, see gaps).
- Nearest-neighbour filtering is project-wide; do not anti-alias.

## Replacing the placeholders

1. Draw the sheet at the sidecar's `frame` size with the documented rows/columns, using the palette's source colours for swappable regions.
2. Overwrite `content/sprites/<id>.png`. Adjust the sidecar only if the layout changed.
3. Run the tests (`godot --headless --path . -s tests/test_runner.gd`); the sheet tests check size, animations and directions.
4. Look at the CI screenshot artifacts.

To regenerate the placeholders: `node tools/gen_placeholder_sheets.js`.

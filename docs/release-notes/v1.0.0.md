# v1.0.0

M4, polish: the 1.0 of the open-source game, built by `release.yml` for Windows, Linux and macOS from one tag. Placeholder art and audio; the title screen says so. The Steam launch waits on three hand-offs (below).

## What is new since v0.3.0

- **Difficulty and Iron Weave.** Story, Balanced and Tactician as rules overlays; Iron Weave as one save, Mortal, no reloads, remembered on your account.
- **The creator as the first screen** of a new game: appearance (a tone and an accent), a placeholder portrait, locked origins named, a preview of what each attribute point buys.
- **Every text panel has a face and a history.** Portraits from the rig, a saved dialogue log shown in the panel and the journal, a tracked quest on the HUD, the Roster and the Quarters as one screen.
- **Pad and Deck.** The stick walks and glides the combat cursor at its tilt; rumble; text size with a Deck default; `--perf` on the status line; a performance budget every map and the largest Shard of every biome stay under, in CI.
- **Saves and settings.** A saves screen with titles, thumbnails and a question before overwriting; three autosaves; Music and Sound buses; a colour-blind pass; a settings screen grouped with a hint per row.
- **Localization scaffolding.** Every string through one table, languages as JSON files a mod can ship, a translator's template written by CI, and a pseudo-locale every screen passes.
- **Art, audio, Steam and Apple, as far as a checkout goes.** Glow lives in the engine (a lighting pass, a screen-effects pass with a CRT); every race, enemy and sound says whether it is a placeholder; recorded files drop in beside their sidecars; the Workshop round-trips without a client; the macOS build notarizes itself on a tag once the Apple secrets are in. Each track has a status report and a checklist.
- **Balance passes** on fights, economy and approval, measured by the harness: medkits and a breather, a lighter depth curve, bosses that wind up.

## What 1.0 is, and is not

- The campaign test is the gate: every faction path and the unsworn one, in Story-Protected and Mortal, on every difficulty, plus an Iron Weave run, green in CI on every tag. It wins fights by fiat and proves wiring, not balance.
- Nobody outside the author has played it. `docs/playtest.md` is the script and `-- --playtest` writes the log.
- Art and audio are generated placeholders. `docs/art-status.md` and `docs/audio-status.md` list every one; the audio gate (`tools/audio_status.gd --strict`) stays red until the last file lands.
- Steam is wired but has never touched a live client; macOS is ad-hoc signed until the five Apple secrets exist. `steam/READINESS.md` and `apple/READINESS.md` name the blockers; the two checklists are the live steps.
- Mods are folders of JSON with a validator and an example; nobody outside the repo has written one.

## Running it

| Platform | File | Run |
|---|---|---|
| Windows | `neon-weave-v1.0.0-windows.zip` | unzip, run `neon-weave.exe` |
| Linux | `neon-weave-v1.0.0-linux.tar.gz` | untar, `./neon-weave.x86_64` |
| macOS | `neon-weave-v1.0.0-macos.zip` | unzip, right-click → Open the first time (ad-hoc signed until notarized) |

Command line: `-- --deck` for Deck text size, `-- --perf` for fps on the status line, `-- --playtest` for the log, `-- --demo` for the demo boundary, `-- --fx=off` and `-- --no-lighting` for a flat frame.

Saves live under the Godot user data directory (`user://`). Saves from v0.3.0 load; the difficulty of an old save is Balanced.

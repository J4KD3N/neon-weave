# v0.2.0-demo

The first tagged build of Neon Weave: the Act 1 demo slice, built by
`release.yml` for Windows, Linux and macOS from one tag.

## What is in it

- **Title screen** with New game (Story-Protected or Mortal), Continue, Load, Settings and Quit. Settings and key/pad rebinding persist under `user://`.
- **Act 1, The Waking**: the Bastion plaza, the yard, the Gate Road, Relay Station Nine, a depth-2 extraction and the Undercity Throat, ending at first contact with the Choir and an end panel. One map per beat; no writing pass yet.
- **Three companions** (Sera, Kaj-7, Dax) with recruit, talk and banter lines, a personal quest each, and approval that moves with your choices. The Lattice envoy waits on the plaza once the road is open.
- **Six classes** with resource loops, eight subclasses at level three, six talents and the Arcanum respec, all from the Weave (T at home).
- **Two Shard biomes** (Rusted Undercity, Verdant Datacore) with secrets, Cipher vaults, relay waypoints, merchants, a distance ramp and loot rarity; the Beacon's level unlocks the second.
- **Turn-based combat** with four action points, cover, high ground, surfaces, five AI archetypes, elite and boss tiers, depth scaling, hover previews and move undo.
- **Controller** support end to end (`docs/controller.md`); Steam Input template in `steam/`.
- **Audio**: synthesised placeholder sound and music on every event.
- **Steam-free**: achievements and cloud saves sit behind `Platform` with the null backend; nothing talks to Steam in this build.

## Known limits

- Art and audio are generated placeholders (the title says so). See the art assumption in `docs/m2-plan.md`.
- The demo is short: well under the planned 2–3 hours. The step from the depth-2 extraction to the Throat is not authored in data yet.
- macOS build is ad-hoc signed and not notarized: right-click → Open, or `xattr -dr com.apple.quarantine` on the app.
- Saves from a different content version load by index and may misplace deltas (S27 adds the check).
- Balance is unplaytested beyond the author.

## Running it

| Platform | File | Run |
|---|---|---|
| Windows | `neon-weave-v0.2.0-demo-windows.zip` | unzip, run `neon-weave.exe` |
| Linux | `neon-weave-v0.2.0-demo-linux.tar.gz` | untar, `chmod +x neon-weave.x86_64`, run it (Steam Deck: add as a non-Steam game) |
| macOS | `neon-weave-v0.2.0-demo-macos.zip` | unzip, right-click → Open the first time |

Mods go in a `mods/` folder beside the executable or in `user://mods`.

## Verification

- CI: tests green on the tag, all three exports produced, the Linux build booted to the title under Xvfb and rendered a frame (`smoke-title` artifact).
- The release job does not run the Windows or macOS binaries; those are opened by hand (see the release PR for what was checked).

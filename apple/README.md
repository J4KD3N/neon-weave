# Apple

Everything macOS-specific lives here (S59, D-114). The export preset `macOS`
in `export_presets.cfg` builds a universal (x86_64 + arm64) `.app` in a zip
from the Linux release runner; without Apple credentials it is ad-hoc signed,
which runs on the builder's own Mac and warns on everyone else's.

- `entitlements.plist` — the hardened-runtime entitlements the signed build
  uses (`codesign/entitlements/custom_file` in the preset).
- `CHECKLIST.md` — the nine live steps that need the Developer Program and a Mac.
- `READINESS.md` — generated by `tools/apple_check.gd`: what the checkout
  proves (bundle id, universal, versions in step with the project, the
  entitlements, the workflow's sign step) and what still needs the secrets.

The release workflow (`.github/workflows/release.yml`) signs and notarizes
with [rcodesign](https://github.com/indygreg/apple-platform-rs) on Linux, no
Mac in the loop, when the five `APPLE_*` secrets exist: it installs rcodesign,
tells Godot where it is, flips the preset to rcodesign signing and rcodesign
notarization for that run, and passes the credentials through Godot's
`GODOT_MACOS_*` environment overrides. The committed preset keeps signing at
"disabled" so a fork without secrets exports exactly as before.
